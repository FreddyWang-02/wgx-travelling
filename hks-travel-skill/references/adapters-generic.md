# 其他 Agent 与通用 MCP 适配

其他 Agent 无需识别特定品牌。先枚举可调用的站点、数据库、宿主身份、权限规则、只读发布、版本控制、函数、Secret 和对象存储工具，再生成能力清单交给 `select_deployment_target.mjs`。

完整适配器需要满足以下产品结果：

- 同域或允许安全跨域的静态托管；
- 持久化数据库或等价文档存储；
- 所有者可以编辑与保存；
- 分享者可以读取且无法写入；
- 原生版本控制、条件写入或保存前版本复查；
- 每位用户独立项目或独立数据域。

可以使用浏览器 SDK、宿主身份、数据库规则、公开只读集合、发布快照、服务端 API、SQL、文档数据库或 KV。字段级拆表不属于首版要求。对象存储只影响附件入口。前端通过 `window.TRAVEL_HOST_ADAPTER` 使用非 HTTP 宿主能力。

Agent 找到多个候选时选择免费、宿主原生、用户配置最少的一项。缺少持久化、只读隔离或冲突识别时继续检查下一个候选，禁止用静态 HTML 代替完整交付。
