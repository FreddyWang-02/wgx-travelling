# 航班检索、推荐与回显规则

## 已预订航班

1. 使用航班号、出发日期和出发机场共同查询，优先调用 Agent 已有航班 MCP、航司、机场或权威航班数据连接器。
2. 回填承运方、出发与到达航站楼、登机口、计划起飞和到达时间、值机截止、登机时间及建议到达机场时间。
3. 航站楼、登机口和值机、登机时间属于高频变化数据。来源写入 `freshness.kind = "live"`，有效期最长 6 小时；出发当日再次核验。
4. 查不到的字段保持空值并在界面显示 `—`，禁止根据常见规则猜测航站楼、登机口或班次。

## 未预订航班

1. 根据用户已确认的出发日期、机场和计划时间窗口检索真实可查班次。
2. 选择一趟衔接行程合理的班次作为默认建议，同时保留其查询来源和核验时间；必要时简要列出备选。
3. 推荐记录使用 `status = "planned"`。用户明确提供订单或确认已预订后，才能改为 `booked`。
4. 价格只在当前来源明确提供时回显，并标注币种、查询时间和价格条件；无来源时显示 `—`。

## 编辑与显示

- 交通编辑器允许用户修改航班号、承运方、航站楼、登机口、建议到达机场、值机截止、登机、起飞和到达时间。
- 关键节点写入 `milestones[]`，使用 `airport_arrival`、`checkin_close`、`boarding` 等标准 `kind`。
- 出行票卡读取同一条 `transportSegments` 记录，保存后立即刷新关键时间与状态。
- 查询与推荐不执行预订、锁座或支付。任何购买操作均由用户在外部官方渠道明确完成。
